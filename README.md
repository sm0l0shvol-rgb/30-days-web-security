# 30-days-web-security
30-day web security challenge: PortSwigger and HTB labs, hands-on practice, and penetration testing write-ups.
The goal of this project is to develop practical web application security skills through hands-on exercises, vulnerability research, and penetration testing labs.

🎯 Learning Objectives
Understand HTTP, HTTPS, TCP/IP, cookies, and session management.
Learn to identify and analyze common web vulnerabilities.
Practice web application security testing using Burp Suite.
Complete hands-on labs from PortSwigger Web Security Academy and Hack The Box Academy.
Document technical findings, exploitation steps, and remediation techniques.
Build a practical penetration testing portfolio.
🛠️ Tools & Platforms
Burp Suite — HTTP traffic analysis and security testing
Kali Linux — Security testing environment
curl — HTTP request testing
tcpdump — Network traffic analysis
PortSwigger Web Security Academy — Web security labs
Hack The Box Academy — Hands-on cybersecurity training
